# Lulen — Windows 快速启动面板

仿 Rolan、对标 [Maye](https://github.com/25H/Maya) 的开源快速启动器。Python + PySide6 实现,只有一个悬浮小面板:全局热键呼出,把东西拖进来,点一下就启动。

![深色主题](shots/panel-v2-dark.png)

## 功能

- **全局热键呼出/隐藏**:默认 `Ctrl+Alt+L`(与 Rolan 冲突时自动回落并气泡提示),失焦自动隐藏,ESC 也可关闭
- **拖拽添加**:从资源管理器把 应用 / 文件 / 文件夹 / 网址(含 `.url` 文件、裸域名如 `github.com`)拖进面板即成为条目,支持多选一次拖入
- **自动图标**:自动提取 exe/lnk 图标,网址自动后台抓取 favicon
- **单击启动**:应用(可带参数、工作目录、管理员运行)/ 文件 / 文件夹 / 网址 / 命令 五类条目,启动后自动隐藏面板
- **分组多页**:页签切换、滚轮在页签上滚动换组、**拖动页签排序分组**、页签右键重命名/删除、拖动条目到其他页签即跨组移动(悬停自动翻组)
- **拖拽排序**:面板内拖动即重排,自动多列布局,面板高度随内容自适应
- **边缘拖拽调大小**:鼠标贴到面板边缘出现缩放光标,按住拖动即可改长宽;松手自动换算成列数/行数保存(锁定位置时同样锁定大小)
- **命令条**:显示面板后直接打字 —— 过滤条目(支持**拼音前缀**,如输 `jsb` 匹配"记事本"),回车启动第一个结果;前缀命令:
  - `>` 命令 —— 在新终端窗口执行,如 `> ping example.com`
  - `<` —— 打开 Windows 运行对话框
  - `s 词` 百度 / `b 词` 必应 / `g 词` 谷歌 / `d 词` DuckDuckGo
- **条目快捷键**:右键 → 条目快捷键,全局注册,无需呼出面板直接启动
- **右键菜单**:运行 / 管理员运行 / 在资源管理器中显示 / 复制路径 / 编辑(名称、类型、参数、工作目录、自定义图标)/ 移动到分组 / 删除
- **参数变量**:条目参数支持 `%mp%`(条目所在目录)、`%mr%`(所在盘根)及系统环境变量
- **主题**:深色 / 浅色 + 自定义强调色,面板不透明度可调
- **其他**:开机自启(HKCU Run)、单实例(重复启动唤出面板)、窗口位置记忆、位置锁定、配置导出/导入、配置文件原子写入 + 自动备份(`config.bak.json`)

## 运行

依赖只有一个 PySide6(+ 可选的 pypinyin):

```bash
conda create -n Lulen python=3.12 -y
conda run -n Lulen pip install -r requirements.txt
conda run -n Lulen python main.py
```

命令行参数:

| 参数 | 作用 |
|---|---|
| `--hidden` | 启动后仅驻留托盘(开机自启用) |
| `--selftest` | 离屏自检(热键解析 / 模型 / 持久化 / 渲染) |
| `--screenshot x.png` | 渲染面板截图后退出(隔离临时配置) |
| `--theme dark\|light` | 截图模式指定主题 |
| `--fresh` | 忽略现有配置启动 |

## 配置

配置位于 `%APPDATA%\Lulen\config.json`,结构一目了然(分组 → 条目数组),可手动编辑;损坏时自动回退 `config.bak.json`。用环境变量 `LULEN_HOME` 可把数据隔离到任意目录(便携模式 / 测试)。

## 测试

```bash
python main.py --selftest   # 20 项:热键解析、类型识别、配置往返、模型过滤/移动、渲染
python ui_smoke.py          # 18 项:真实窗口事件驱动(点击启动、命令条、菜单、分组、拖放、空态)
```

## 设计说明

- **启动**统一走 `ShellExecuteW`,与资源管理器双击行为一致(支持 .lnk、UWP 建议、UAC 提权)
- **全局热键**用 `RegisterHotKey` + Qt 原生事件过滤器转发为信号,无 pywin32 依赖
- **单实例**用 `QLocalServer`,服务键按配置目录哈希区分,测试实例与正式实例互不干扰
- 条目数据模型 `ItemsModel` 直接持有配置存储中分组列表的引用,视图变更原地写回、统一由防抖定时器落盘
